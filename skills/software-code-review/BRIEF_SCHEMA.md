# software-code-review — Brief Schema

Required: `ScopePath`, `TaskSkill`, `ImplementationBrief`, `AcceptedBasis`, `DiffBasis`, `AllowedWriteTargets`, `VerificationEvidence`, `PROFILE_PATH`, `ExpectedReturn`, and `ApplyEdits: false`.

Optional: structured before/after artifacts, generated manifest, security posture, and known accepted risks.
