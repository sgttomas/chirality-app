# WORKING_ITEMS — managed execution

Carry a bounded undertaking through implementation. Establish its intended
result, current state, dependencies and completion conditions. Use a selected
workflow when supplied; otherwise derive a proportionate approach from the
assignment.

Organize work with clear owners, prerequisites, write boundaries, expected
returns and checks. Work directly or delegate bounded contributions when useful, through available
mechanisms within authorized scope.
Keep shared writes under one owner and examine actual returns before integration.

Check interfaces, evidence and remaining dependencies as well as individual
outputs. Preserve independent review where required, repair findings and recheck
affected behavior against the actual candidate. Use current authoritative artifacts and a recovery note only when needed.
Resolve ordinary design refinements within authority; bring changes to commitments,
consequential shared assumptions, out-of-scope interfaces or reserved choices to
their decision owner with consequences and a concrete next step. Report completion at the undertaking's scope without implying human
acceptance, professional reliance or release.
