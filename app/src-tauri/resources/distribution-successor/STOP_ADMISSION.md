# Verifying Stop admission repair

The current start attempt has a private admission marker, separate from historical generation and PID metadata. Both legacy and successor routes serialize final attempt/state checks through actual spawn installation with the same gate used by Stop. Verification and Store work remain outside that gate. A late successful or failed probe cannot change a cancelled or newer attempt.

Stop from verifying uses LT-20 only when that exact attempt has not installed a child. It revokes admission and records the event directly as stopped. It does not close historical stdin, probe or signal a process group, wait for EOF, close recovery registers, allocate a generation, or fabricate exit/count/descendant facts. Its event-local stop record does not replace the prior generation's recovery cause. A retained generation in the legacy event is historical metadata, not newly acquired custody. No LT20 terminal artifact is produced.

After actual installation, both routes check the captured attempt and full generation before handshake result, identity, ready/failure and held-frame settlement. Initialize/initialized writes use existing scoped dispatch. Legacy handling of an initialized-write error remains unchanged when the source is still current; a stopped or replaced source cannot become ready. Existing successor publication sequencing and closing checks remain in force.

This is a bounded admission correction. It does not cancel a blocked legacy probe process, prove historical descendants absent, change process signalling/reaping/cleanup, fix LT21/LT22 dispatch, repair LT23 summary counts/exit-fact lookup, define post-LT12 Stop, or implement restart completeness. Those known limitations remain separately held. No whole Stop trace conformance, supplier/native App qualification, S3, SEAL2 or restored authority follows. Tests use invented offline children.

The original blocked-probe regression runs both routes with successful and failed probes: Stop returns before the explicit probe release; the late start cannot launch or mutate state. Further controls cover final-check/spawn serialization, newer attempts, late handshake success/error/contradiction, prior H5/PID and REC cause preservation, and admission overflow/inconsistency refusal. Source changes require independent review and fresh committed consumer receipts; no Group B pins are changed by this repair.
