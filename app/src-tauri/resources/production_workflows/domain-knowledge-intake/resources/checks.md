# domain-knowledge-intake: checks before acceptance

1. Every item has a source locator, and every numerical item has a unit and the source edition.
2. Every numerical value used in computation was verified by someone other than its extractor, and the verifier is named by role.
3. Every rule table has tests, each tracing to the source, and the tests pass.
4. Conversions state their basis.
5. Conflicts are listed with both claims. Each is open with its consequence, resolved by inquiry with the evidence, or ruled by the named authority.
6. Expert judgments are attributed, dated and scoped. None is presented as published.
7. TBD items state their consequence for the intended uses.
8. The manifest hashes match the files, and the decision record is outside the pack.
9. Nothing private appears in a pack intended for a public specification.
