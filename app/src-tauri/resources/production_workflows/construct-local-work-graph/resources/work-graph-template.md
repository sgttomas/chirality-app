# Optional generated work-graph view

Generate the relevant neighbourhood from the deliverable dependency sources and
observed implementation/PR facts. Include the observed revision, source
locations, required conditions and unknown inputs. Show non-gating relationships
and cycles without converting them into blockers.

This is a view, not a file to commit or a status table to maintain. Keep current
commitments and conditions in the deliverable files and the change account in
the PR. Agent 0 plans the next coherent slice from the view and the user's
steering; the tool cannot infer completion from a merge or a matching path.
