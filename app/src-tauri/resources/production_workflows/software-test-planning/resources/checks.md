# software-test-planning — QA Checks

1. Every planned test maps to a behavior or risk.
2. Registered checks cite deterministic selection reasons.
3. Negative, boundary, and regression cases are considered.
4. Pass criteria and evidence outputs are explicit.
5. Expensive or consequential gates are identified for the parent or human.
6. Where acceptance criteria were supplied, every claim in each criterion has a check of stated kind, and the plan says how an implementation that misses the claim would fail it.
