# Rust library tests that no pull-request cohort filter selects, with the reason.
# tools/ci/check_lib_cohorts.py reads this file with the library's test list
# (cargo test --lib -- --list) and .github/workflows/app-v4.yml; see its text
# and docs/CI_SELECTION.md.
#
# One entry per line: a test module path, or one test's full path, then ": "
# and the reason. A module line covers the tests directly in that module that
# no pull-request filter selects, not those of its submodules; a line naming
# one test takes precedence over its module's line.
#
# Reasons are of four kinds: the full route only, with the reason where one is
# recorded; selected on pull requests only by a successor-feature filter, with
# its step; selected on pull requests only by a web test fixture, with its step;
# and ignored (#[ignore]), which the full route does not run either: opt-in, run
# by no hosted job unless someone names it, or a child process that a named
# parent test starts, running only where that parent runs. Every ignored test
# has a line of that last kind, whether or not a filter's name matches it.
# A test left to the full route runs on main nightly and on a product dispatch,
# not on the pull request that changes it.
#
# The check does not verify a reason's text beyond the ignored marker: not the
# named feature step, web fixture or parent, nor the full route's command.
# Refresh after cohorts change (removes stale lines only; adds none):
#   cargo test --locked --manifest-path app/src-tauri/Cargo.toml --lib -- --list > /tmp/l.txt && cargo test --locked --manifest-path app/src-tauri/Cargo.toml --lib -- --list --ignored > /tmp/i.txt && python3 tools/ci/check_lib_cohorts.py --list /tmp/l.txt --ignored-list /tmp/i.txt --prune
