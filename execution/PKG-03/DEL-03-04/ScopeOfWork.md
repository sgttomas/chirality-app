# DEL-03-04 — Host boundary and integration guide

## Purpose and Objective Traceability

Give an application builder the integrated receiving guide for adding a host: what the App/shared undertaking supplies, what the host must supply, where each contribution is received, and what evidence supports reliance on it. The **App/shared host-contract integration owner** retains responsibility for the completeness of this DOC_UPDATE deliverable. Its contribution to OBJ-004 is an explicit, usable boundary across workflow, catalog, operation, human-act, record, loop, panel and optional connector contracts. It does not own their separate implementation or the external SWBPIPE construction.
