# S2 first connected staged runtime slice

Status: partial S2 implementation, not production adoption or supplier qualification. Legacy HOSTING remains authoritative and unchanged. No supplier, native launch, credentials, downloads, signing or release operation occurred.

The maintained Rust distribution_preflight module connects exact build-selection bytes and trusted test-anchor digest, method/schema allowlist, exact reference/attestation/evidence resolution, complete descriptor-relative no-follow tree scan, expected/generated comparison, synthetic label callback, full pre-spawn rescan, and synthetic launch callback. The allocated H5 tuple is checked before verification and must match the returned launch tuple. The output is explicitly staged-preflight.s2 and always unverifiable. Production selection is a compiled None sentinel; no external caller can provide an anchor to the private orchestration seam.

The scanner includes root/descendant modes, directories including empty ones, regular-file bytes/size/digest, full path sets and manifest. It refuses links, hardlinks, special entries, invalid names, read instability and detected directory/root replacement. Direct-vendor plans preserve inherited PATH empty entries, reject colon relocation and record wrapper removals. These plans do not themselves execute commands or remove environment variables from a process.

## Remaining S2 work

This slice does not connect to Host.start, a native bundle resolver, isolated H-probe label adapter or actual direct launcher. It does not emit observed-verification.s1 or lifecycle-event.s1, atomically publish their exact bytes, map versionIdentity/supplierStanding through runtime_session/native_items, or establish live-child custody. The observed generation comes from a controlled callback, not an OS child. A future native adapter must handle returned-generation contradiction without orphaning a started child. No runtime reference claim can be verified before qualified S3 reference selection, generated-source correspondence, installed build integrity, actual custody and affected consumer adoption.

Filesystem checks cannot prove future immutability against hostile same-user mutation; stable installed bundle and parent custody remain unestablished. Deterministic pre-spawn mutation is tested, but hostile concurrent race scheduling and exhaustive traversal interleavings are not proven. Build-selection.s2 is a maintained staging representation, not a canonical Design amendment. Its anchor and callback injection are private test seams; source-reviewed compiled production selection remains absent.

## Verification and scope

Synthetic tests only. Test result and candidate hashes are recorded separately after final execution. A first run passed nine tests and failed invalid-name fixture creation because the filesystem itself rejected the bytes with EILSEQ; the test now accepts only that exact native refusal or, where creation is possible, requires scanner refusal. This changes fixture portability rather than the verifier rule. Earlier default and obsolete offline caches lacked dependencies; the prepared cache is used without downloads.

No accepted Design, source pins, packaging/examination code, MEMORY, role/workflow source, or production Host code changed. The sole existing source edit exports the new module. Resources retain historical origin hashes without making dated run paths runtime dependencies. Parent owns independent review, graph/technical adoption and integration; no commit made by this executor.

## Independent review repair R1

The reviewer reproduced an earlier file changing while a later 512 MiB file was hashed. Initial per-file pre/post checks missed that scan-time mutation; it was not merely a check-to-exec race. The repaired scanner retains every initial entry identity stamp and performs a complete final descriptor-relative no-follow metadata and path-set audit after all content reads, including nanosecond ctime and mtime. Regressions cover ordinary mutation and equal-size mutation with original mtime restored; the latter asserts equal size/mtime and changed ctime. This remains a bounded filesystem observation, not an atomic OS snapshot: mutation after a path's final audit, adversarial interleavings or custody unable to establish stability cannot support a production verified claim. Production remains unavailable.
