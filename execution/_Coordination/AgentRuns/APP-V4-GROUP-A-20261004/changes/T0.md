## Result and boundary

All `/private/tmp` literals in App v4 tests and README/EVIDENCE are removed.
The Rust helper invokes `mktemp -d` with an explicit unique template rooted in
`std::env::temp_dir()`, verifies allocation, and canonicalizes the returned path
before use. Canonicalization preserves the strict Codex-home identity check
when the system temp root is a symlink. Its ownership guard removes scratch
homes, probes and workspaces at test return and assertion unwinding; normal
cleanup failures fail the test, while unwinding preserves the original failure.

Node allocates a unique evidence directory under `os.tmpdir()`, supplies it as
`CHIRALITY_TEST_OUTPUT_DIRECTORY`, and removes it in the test-runner after hook
once all schema assertions have completed. The exported files are independent
copies, so removing the Rust workspaces does not remove validation inputs.
Standalone Cargo runs retain their exports in Cargo's test output root for
manual inspection. Fresh Node outputs prevent an earlier run from satisfying
an output-existence assertion. The README's App instructions allocate its home
before configuration, then reuse that configured home on launch; scratch App
workspace retention is explicit because it contains user-inspectable evidence.

application source, Cargo manifest, issue registry, shared graph or MEMORY was
changed. No downloads, sign-in, credential access, live model turns or Git
mutations occurred. The unavailable local provider, plugins/analytics-off
