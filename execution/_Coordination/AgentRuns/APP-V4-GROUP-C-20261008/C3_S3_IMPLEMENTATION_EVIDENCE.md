## Implemented behavior

A current successful native-selected local observation supplies the private
path; renderer arguments contain only session/generation/reference and full
commit IDs. The existing host-owned explicit project guard rejects absent,
unknown or mismatched project association. No renderer root/path, upward
repository search, branch resolution or working-tree substitution is admitted.

The adapter checks ordinary or linked worktree association, backlink/common
metadata, supported object format and object storage. Metadata reads have an
actual 1 MiB cap. Storage census is iterative with depth 128, 65536 entries and
8 MiB capture limits, uses raw path bytes, and reports unsupported capability
rather than silently dropping enumeration. It refuses symlinks, alternates,
unsupported extensions/layouts and observed association changes.

Fixed installed Git runs with a cleared environment, minimal private admin
configuration, validated object directory, required no-fetch/no-replace/no-lock
controls and deny-all transport policy. Only raw cat-file and nonwriting typed
hash-object operations read objects; a separate version/capability probe
precedes them. Full IDs are stdin data; raw trees match exact path bytes. Each
returned object is checked using the same installed Git's nonwriting rehash.
This is same-engine consistency, not independent cryptography. Independent
Python hashlib SHA-1/SHA-256 raw commit/tree/blob vectors supply test expectations.

Accepted blob/commit/tree bytes, literal traversal, side budget and request time
are bounded. Rehash input counts against each side's 8 MiB budget; stderr is
cumulative and bounded. Nonblocking pipes, deadline/cancel checks and bounded
process-group kill/direct-child reap handle failure. Side-local failure retains
an independently completed other side as partial. Whole-request abort discards
all new sides and leaves only a prior published result historical. Local snapshot,
caller revision assertion, Git side, and side-bound exact excerpt remain separate.
Raw bounded commit/tree/blob bytes remain in host memory; DTOs cannot recreate
capabilities. No source/account/fact/conclusion/duty/save/send is produced.

The separate panel shows requested pins, side results/gaps, committed text,
mechanistic byte comparison, exact excerpts, responsibility and provenance
limits. Text is escaped. A client request guard prevents a late completed read
reply from overwriting the cancellation reply. Failed/cancelled local selection,
root replacement and stale preparation cannot restore eligibility through an
