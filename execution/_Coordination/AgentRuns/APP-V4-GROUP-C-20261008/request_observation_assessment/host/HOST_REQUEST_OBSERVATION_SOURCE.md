## 2. Closed external types

All objects below deny unknown fields. All integers crossing IPC are canonical unsigned decimal strings: `0` or nonzero digit followed by digits, no sign/space/leading zero/exponent, checked <=u64::MAX. Digests are lowercase 64-hex. Strings preserve UTF-8 exactly, no normalization. Host metadata strings are bounded at 256 UTF-8 bytes apiece. H5 is exactly `{appSession,home,spawnCounter}`; spawnCounter is the decimal external projection of the original number, not a change to H5's internal or REC schema.

Selector = `{generation:H5,rpcId:Decimal,requestRef:String}`. It is a lookup selector, never proof. Copying/replaying a selector may legitimately request a NEW observation of the same still-retained source; no page-issuance capability or replay ban is claimed. The fresh actual Host lookup/capture supplies the observation warrant, not selector provenance. Registry RPC key must be a genuine numeric u64 request ID and agree with original frame ID. Exact full H5 and requestRef must match the looked-up SourceEvidence. Home is the original opaque App home identity, not a path, person or account identity. H5/appSession supplies source identity; no fabricated durable Host UUID.

Selector page input = `{after:Decimal,through:Decimal|null}`. First page after=0/through=null captures current next_id under Inner. Later through is a navigation watermark, not caller authority, and must be <=next_id with after<=through. Visit at most 64 consecutive numeric RPC slots (checked arithmetic), lookup each by its exact decimal key, without enumerating/sorting/cloning the map or journal. Return `{format:"chirality.host-request-selector-page.v1",through:Decimal,nextAfter:Decimal,done:bool,rows:[Selector],skippedUnexportable:Decimal,scope:"actual-selected-host-retained-requests"}`. Each row passes bounded shallow eligibility: method exactly turn/start, auth_projection false, params has nonempty bounded threadId and exactly one input whose type=text and text is a string <=16KiB. This is candidate eligibility, not complete native schema validation. Unknown request params are not discarded from frame identity at inspection. Empty pages advance; skipped rows are never silently called complete coverage. Project/role/auth data are not listed. Check per-row escaped serialization <=1024 bytes before copying; skip oversize metadata and count it. Maximum page serialization 128KiB; hard refusal rather than truncation if violated. No cold lookup, inference from client-record rows or guessed requestRef construction.

## 3. One cut, exact states and routing

Consumer takes its original active Home Arc, releases HomeRouter, invokes Host, then rechecks actual routing outside Host. No IO, waits, sender/receiver calls or journal acquisition here. Mutex poison yields typed unavailable. Returning copied observations does not extend source currentness.

At the single Inner cut, verify the original weak source upgrades and points to this Inner, map key/frame ID, exact selector and bounds. Do not clone SourceRequest (it clones the entire frame). Verify client index with get(), not unchecked indexing. Failure or inconsistent retained pairs refuses without mutation. Current-at-cut iff original H5 == current generation, state ready, and server_requests reports generation not closed. Otherwise an actually retained original is historical-retained. Closed/superseded records may remain observable; a foreign/missing record is unavailable. No currentness after lock release or cold process restart is promised. receiptWatermark belongs to captured currentGeneration; never compare it to historical source receipt positions as though the domains matched.

AttemptPosition is SourceEvidence.attempt_position, not request registration or response receipt. In-progress dominates; completeObserved and errorObserved remain independent. Complete means write_all+flush returned successfully for that retained request, not supplier delivery/ack. With no attempt, source_limit may indicate prewrite refusal but its arbitrary error text is not exported. Response position is only actual response_position and requires response presence; absent response has null position/frame. A response can precede write completion or coexist with failure; preserve both observations. WaitingEnded is actual retained record/base flag, not cancellation. canonicalClientRecordAvailable follows actual object existence/source_limit/failed-write-plus-response rule; it does not validate full source meaning.

Request-bound project association is UNKNOWN in this slice. ## 4. Digest and finite engineering bounds

Method host-retained-sorted-json-v1 is SHA256 of compact JSON serialization of the borrowed retained serde_json::Value: object keys ordered lexicographically by their UTF-8 bytes, arrays in retained order, strings via serde_json escaping, numbers via the pinned serde_json Number serializer, no whitespace/newline/Unicode normalization/domain prefix. Record exact dependency/source pins in implementation evidence. This is a method-specific parsed-value identity, neither original wire identity nor AA-CAP PF1 nor an artifact-file hash. Hash writer aborts before exceeding 128KiB per frame. Text hash is separately SHA256 of original decoded string UTF-8 bytes. No second frame buffer.

Before clone, digest or recursive serialization: bounded borrowed walk of request and optional response, each <=4096 nodes, depth16 (root depth0), each container width128, aggregate key/string UTF-8 <=128KiB, streaming serialization <=128KiB. Check len() before touching oversized collections/strings; count checked cumulative bytes/nodes; fail before allocation or copy. Stack traversal and at most128 borrowed key references per level; no cloned subtree or sorting unbounded keys. Depth check precedes recursive call. Text<=16384 UTF-8 bytes; metadata strings<=256 bytes. Bounded response walk includes all fields although they are not exposed. Overflow/oversize returns whole export unavailable, no truncated frame digest or misleading text.

Output typed projection and its escaped compact IPC serialization <=128KiB; preflight escaped lengths and capped serialization prevent exceedance. One operation may retain only selected bounded text/metadata plus traversal/digest scratch and final output. Proposed acceptance ceiling: <=512KiB incremental live allocation for this exporter operation, including simultaneous typed projection and encoded return, checked with a dedicated allocation test/explicit peak accounting before code acceptance. This does not count existing Host transcript, framework's earlier IPC decoding, future renderer copies or total App RSS. Existing native request acceptance is NOT capped or changed; oversized observation refuses only the new view. Page inspects at most64 slots with shallow checks, not64 full-frame hashes. No R2 product N/S/D/T/Q, retention or immutable store policy is selected. Finite work does not imply a wall-clock mutex wait guarantee.
