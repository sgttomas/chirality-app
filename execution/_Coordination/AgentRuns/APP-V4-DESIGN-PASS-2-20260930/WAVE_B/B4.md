for R11 that R11 does not list … not yet defined here. Both texts stay …"

**Options.**
1. **Add both to R11 as written limits** (writer-side). "Resubmission without prior observation": written with the resubmission's R7 entry when the previous submission of the same proposal identity is *outcome unknown* and no read by that identity is recorded between them; subject = the resubmission entry; supplier DEL-03-03 (App runs over X). "App-restart interruption": written by the App writer at W-0 on relaunch against each submission sent without an observed result; each stays *outcome unknown*, observer App; not a run end (EXEC §4.12). Format: two evidence-limit labels (minor step 0.1 → 0.2).
2. **Derive both on read** (no new labels): the reader finds the order from R7 entries, and the restart from the log's session boundary. No writer change; but every reader (DEL-04-02, DEL-09-06, DEL-09-09, DEL-09-11) must implement the same rule, and ADAPTER's "recorded as an evidence limit" would be reworded.
3. **Mixed:** (1) derived on read, (2) written by the writer (only the App knows it restarted).

**Recommendation: option 1.** Both conditions are facts the writer can see
at write time; ADAPTER, XT (L-XT-3) and CA expect a recorded limit; a
written limit is what the record's own completeness rules already use
("record write failed", "partial entry not recovered", RS §14). Consequences
