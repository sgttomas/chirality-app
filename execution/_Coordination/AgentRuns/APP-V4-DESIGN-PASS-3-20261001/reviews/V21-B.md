EXEC/WD, and EXEC says it was checked against NPTD.**

- **Where.** EXEC-v0.7 §3.4 EV-3a row `agent-delegation` (l.947) and the

  NPTD-v0.2 §7.1 (l.356–369) and `DEL-01-03/Design/prototype/npt_model.py`
  `delegation_availability` (l.630–644).
- **Quotes.** NPTD §7.1: "`disabled`, `namespaceTools` false or
  `multi_agent` false → **missing**, the view absent with its reason; a value
  not read or null → **not established**". EXEC EV-3a: "If `namespaceTools`
  reads false the reference is **not established**, limit 'provider may not
  receive delegation tools' … `multiAgentVersion` null or not read → *not
  read*". WD §4.2.5: "present when … not `disabled` and the provider accepts
  `namespace` tools …; an effective `features.multi_agent = false` reads
  missing; otherwise not established". EXEC l.86: "J-5: EV-3a row confirmed
  against NPTD-v0.2 §7.1 …, no further change."
- **Checked.** Read both texts and both prototypes. `npt_model.py` returns
  `("missing", "this provider does not accept the namespace tools …")` for
  `namespaceTools` false and tests `multi_agent = false` before the version;
  `_delegation` returns `"limit"` → *not established* for `namespaceTools`
  false and returns *not read* for a null version before looking at
  `multi_agent`. So for the same reads (e.g. a provider reporting
  `namespaceTools` false, the LM Studio case §7.1 describes; or
  `multi_agent = false` with no `model/list` read) the view says *missing*
  and the required-tool report says *not established*. Both files cite
  R18-1 C-04, which defines "available" and the `multi_agent = false` case
  only; it does not say how `namespaceTools` false reads, so neither text is
  wrong by the ruling, but they are a join that states different values while
  EXEC records that they agree. HOSTING-v0.9 HCG-A08 is compatible with
  either.
- **Why it matters.** Criterion (2): the same supplier signals produce two
  states under the same vocabulary (*missing* / *not established*) in two
  receivers of HOSTING HCG-A08, and the EXEC change table claims a
  confirmation that did not hold.
- **Fix.** An integrator line under C-04 choosing one reading (for example:
  `namespaceTools` false → *missing* in the view and *not established* with
  the delegation limit in the report, stated as a deliberate difference; or
  one value in both), then align NPTD §7.1 and `npt_model.py` or EXEC EV-3a,
  WD §4.2.5 and `_delegation` (with the evaluation order of
  `multi_agent = false` against a null version), rerun both prototypes, and
  correct EXEC l.86.
