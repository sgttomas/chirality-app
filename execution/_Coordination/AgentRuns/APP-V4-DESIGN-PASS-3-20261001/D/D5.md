### 1.1 Main design choices

1. **Library model (K-6).** A slot holds a series of immutable revisions in a revision store; a ledger line (citing the A15 record) is the commit point; a published copy at Root's `workflows/<name>/` is kept for portability but is never authority. "Registered" standing is computed from ledger **and** A15 record **and** recomputing bytes (LS-1), because D3 leaves the sandbox to the user and the App cannot stop an agent writing files.
2. **"Made from" (SP-3).** A draft registers as a new revision when its **App-recorded** draft base is a revision of the target slot **or its derived-from lineage reaches one**. The second limb keeps CA §4, EXEC RT-6 and WD-EX E3 (the round trip ⟨rev-A2⟩ → host ⟨rev-3⟩ → App ⟨rev-A3⟩ under one name) without rework. Otherwise a same-name draft is refused with "Choose a new name".
3. **derived-from vs prior revision (R17-11).** A new revision's derived-from is its draft base (WD's parent-identity meaning); the prior revision is the slot's latest at review. Both are carried; they differ for a stale base or a round trip.
4. **Trials (K-7).** "Try in a conversation" opens an ordinary conversation, pre-fills (does not send) a message naming the draft; no run, no workflow supply, no checkpoint recording; only an App-kept trial pointer.
5. **Review binding (K-8).** Review takes a snapshot; the A15 descriptor binds its content identity, which equals the revision value (ID-2); the act control refuses capture once the draft or the slot changes; publication copies the **snapshot**, so registered bytes are reviewed bytes. Review is a presentation, never an act.
6. **One act, one revision (RB-8).** An A15 whose registration did not complete is recorded as not effective; only relaunch reconciliation of the same, unchanged attempt may finish it.
7. **Selection pinned (SL-2, PROPOSED)**; unqualified names offer project → user → bundled → host candidates and never resolve silently (SL-3, PROPOSED); resolution always from the store.
8. **Pre-v4 library content is not runnable until registered in place (LS-2, DS-7)** — follows K-7, flagged for the owner (U-WR-4).
