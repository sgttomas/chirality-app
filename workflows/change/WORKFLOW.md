# change

Prepare and close a coherent Git change with inspectable evidence and existing human decision rights.

WORKING_ITEMS coordinates this undertaking and assigns bounded contributions to TASK.

## Method

1. Inspect the working tree, ownership, target branch, and accepted change scope.
2. Prepare the isolated change and resolve integration issues while preserving unrelated work.
3. Run applicable registered checks and review the final diff before CI, commit, or push.
4. Present the state report and carry out already authorized closeout actions; route consequential merge or publication decisions under the owning project’s rules.
